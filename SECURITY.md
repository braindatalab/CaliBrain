# Security Policy

## Supported versions

Security fixes are provided for the latest released version of CaliBrain.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting instead: open the **Security** tab
of the repository
(<https://github.com/braindatalab/CaliBrain/security>) and choose
**Report a vulnerability**. Include the affected version, a description of the
problem, and steps to reproduce it if possible.

You can expect an acknowledgement of your report, and we will keep you informed
about the fix and the release that contains it.
